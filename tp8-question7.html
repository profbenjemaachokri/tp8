Propriétés initiales : largeur : 100px ; hauteur : 100px ; couleur de fond : rouge ; bordure : 2px solid black.

Remarque : chaque bouton lance une animation différente. Le bouton « Arrêter » arrête l'animation et replace le bloc à son état initial.

Pour l'animation de largeur, 100% et 50% sont calculés par rapport à la largeur de la zone.

Comprendre les images clés : @keyframes

La règle @keyframes permet de définir les différentes étapes d'une animation.

  • 0% : état initial de l'animation.
  • 50% : état du bloc à mi-parcours.
  • 100% : état final de l'animation.

Exemple : animation de couleur et de position

@keyframes couleurPosition {
  0%   { background: red;   left: 0;   top: 0; }
  25%  { background: yellow; left: 200px; top: 0; }
  50%  { background: blue;  left: 200px; top: 200px; }
  75%  { background: green; left: 0;   top: 200px; }
  100% { background: red;   left: 0;   top: 0; }
}

À retenir : les pourcentages indiquent à quel moment de l'animation appliquer les propriétés CSS. Les valeurs et les propriétés peuvent changer à chaque étape.
